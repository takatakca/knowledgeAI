## Purpose

This is the annual cleanup baseline for the professional TAKATAK portfolio. It reconciles the connected GitHub organization, TAKATAK project context, and business-hosting/domain evidence available as of 2026-10-06.

It is a **working operational inventory**, not a legal ownership registry and not proof that every listed domain is currently active, renewed, deployed, or controlled by the same registrar account.

## Evidence classes

- **OBSERVED-GITHUB**: repository currently visible in the connected `takatakca` GitHub organization.
- **OBSERVED-HOSTING**: domain observed in MochaHost invoice, renewal, migration, cPanel/account, or other business-hosting evidence.
- **KNOWN-PROJECT**: established in TAKATAK professional project history, but current deployment/registrar state still requires verification.
- **NEEDS-AUDIT**: a name or asset exists, but purpose, canonical domain, status, ownership, or current deployment is incomplete/ambiguous.
