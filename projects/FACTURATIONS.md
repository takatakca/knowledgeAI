# Facturations

## Role
Facturations is an accounting/evidence-oriented TAKATAK project discussed as a source of reusable financial-record patterns.

## Reusable principle
Financial evidence should favor append-only / immutable records where historical integrity matters.

Corrections should be represented through explicit adjustment/reversal records rather than silently rewriting past financial evidence.

## Status rule
Do not assume historical Facturations concepts are production-approved. Reconcile them with the current accounting/control-tower and ledger architecture before reuse.
